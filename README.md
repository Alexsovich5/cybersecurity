## Project Overview

Comprehensive cybersecurity hardening initiative implementing network perimeter defense with pfSense, intrusion detection with Snort IDS, host-based security with OSSEC, and centralized logging with ELK Stack.

**Role**: IT Administrator
**Organization**: Zambaiti
**Duration**: March 2018 - August 2018
**Project**: #24 of 30 in IT Career Portfolio

## Business Impact

- **95% Reduction in Security Incidents**: Multi-layered defense
- **Real-time Threat Detection**: Snort + OSSEC correlation
- **Compliance Ready**: Centralized audit logging
- **Automated Response**: Playbook-driven incident handling

## Technology Stack

- **pfSense 2.4**: Network firewall and VPN
- **Snort 2.9**: Network intrusion detection
- **OSSEC 2.9**: Host-based intrusion detection
- **ELK Stack 6.x**: Log aggregation and analysis
- **Ansible 2.5**: Automated deployment
